# SISGED – Front-end (MVP estático)

Versão estática do Sistema de Gestão Acadêmica (SESI/SENAI) para publicação no GitHub Pages e no Cloudflare Pages.

- Telas: login (simulado), painel, horários, instrutores, salas e relatórios.
- Tecnologias: HTML, CSS e JavaScript puros, sem build.
- Dados: fictícios, definidos em `assets/js/sisged.js`.
- Estrutura: `index.html` na raiz, `assets/css`, `assets/js` e `assets/img`; todos os caminhos são relativos.

## Limitações do MVP
Não há PHP, banco MySQL/MariaDB, autenticação real nem gravação de dados. Cadastros e movimentações (que dependem de servidor) ficaram fora desta versão.
